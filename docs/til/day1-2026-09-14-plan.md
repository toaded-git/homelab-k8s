## 배운 것

### kubeadm 을 호스트에 직접 못 올리는 이유

Docker 가 쓰는 containerd 는 `/etc/containerd/config.toml` 에 이렇게 박혀 있다.

```toml
disabled_plugins = ["cri"]
```

쿠버네티스는 컨테이너 런타임과 **CRI** 로 말한다. 그러니 이 플러그인을 켜고 containerd 를 재시작해야 하는데,
그러면 **NAS 컨테이너가 전부 같이 재시작된다.** Jellyfin·Immich·Samba 가 돌고 있는 집 서버에서는 받아들일 수 없다.

→ **VM 으로 분리**하기로. 클러스터를 부수고 다시 세워도 NAS 는 영향이 없다.

### swap 정책은 배포판마다 다르다

- 업스트림 쿠버네티스: swap 을 끄는 게 원칙 (kubelet 이 켜져 있으면 기동을 거부)
- k3s: `failSwapOn=false` 로 기본 허용

같은 쿠버네티스인데 전제가 다르다. 문서를 섞어 읽으면 헷갈린다.
